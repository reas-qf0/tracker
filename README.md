# Tracker

 (Currently unfinished)

A lightweight app to track your listening habits.

Features:
- Detect playing tracks via notifications
- Display history and basic statistics about artists, albums and tracks
- Show a daily report with your top artists, albums and tracks for that day

Key differences:
- Tracks exact time played in addition to number of plays
- Local first - data loads and shows almost instantly
- Cloud save via Firebase Firestore

Plans:
- Ability to self-host your own sync server
- Automatic forwarding to other music tracking sites such as last.fm and ListenBrainz
